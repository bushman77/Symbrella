# Guardrails Quick Link

Project guardrails live in
[`SYMBRELLA_PROJECT_GUARDRAILS.md`](./SYMBRELLA_PROJECT_GUARDRAILS.md).

Large refactors or boundary changes require an approval token in chat:

```text
Approve: P-### (FileScope: path/or/scope)
```

Example:

```text
Approve: P-002 (FileScope: apps/brain/lib/brain/lifg)
```
